Privacy and data handling

Second Brain Local Pilot is a private application operated for its owner. This page describes its current data handling; it is not an invitation to upload information or register.

Google account data

The application requests the Google Drive drive.file permission. It uses this permission to store, retrieve and verify files created or specifically opened with the application. The selected account's identity is checked to keep the connection associated with the owner. It does not request unrestricted access to the account's entire Drive.

Storage and processing

Source files are held in the connected private Google Drive. Structured records, notes and generated results are held in the owner's private application database and storage. A separate Markdown projection and encrypted data backups can be kept on the owner's computer. Connection secrets are protected separately from ordinary data backups. Data is not made public by creating a note or backup.

Optional AI processing

External AI processing requires the application's explicit approval flow for the exact request or chat context. Document content is not automatically sent to an AI provider merely because a file is stored. Where approved OpenAI API processing is used, the application requests store=false; provider-side abuse-monitoring retention may still apply. The request details and budget are displayed before approval.

Control and deletion

The owner can revoke the Google authorization through the Google account's third-party access settings. Content deletion in the application is reversible soft deletion; original files in Drive and older encrypted backup copies can remain until separately removed by the owner. Backups and projections follow their configured retention and refresh behavior.

Limited use

Google user data is used for the application's document and knowledge-management functions. It is not sold, used for advertising, or used to train a general-purpose model by this application. Publication of general notes to a connected tool requires the separate application publication controls. There is no public sharing of medical records or private notes.

For this personal-use application, the support contact is the account listed on its Google consent screen.
