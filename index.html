Second Brain Local Pilot

A private, single-owner application for organizing original documents, source-linked notes, learning resources and tasks.

Google Drive is used to store and retrieve the specific files created or opened with this application. It does not request access to all files in a Google account. Access to the private workspace requires the owner's authentication; this information site does not provide access to the application or its data.

This is a personal-use application, with no public registration or shared workspace.
